# TacticAI 拡張モデルにおける提案手法と工夫点

本研究では、Google DeepMindによる「TacticAI」をベースとし、その幾何学的表現学習および検索アルゴリズムにおいて、以下の2点の独自改良を提案する。これにより、限られたデータ環境下での汎化性能向上と、戦術的意図を汲み取った高度な検索を実現する。

---

## 1. 幾何学的ビュー間の一貫性正則化 (Consistency Regularization)

### 【現状の課題】
TacticAIでは、ピッチの幾何学的対称性（$D_2$ 群：左右・前後反転）を考慮するため、1つの局面から生成した4つの幾何学的ビューを共通のエンコーダに入力し、得られた潜在表現を**単純平均**することで等価性を保証している。しかし、単純平均のみでは、モデルが各ビューから抽出する特徴が必ずしも一貫しているとは限らず、対称性の本質的な理解（不変性の学習）が不十分になる可能性がある。

### 【提案手法】
各ビューから得られるノード埋め込み $H^{(i)}$ 間で、**「同じ潜在表現になるような正則化項（Consistency Loss）」**を導入する。
* **手法**: 各変換ビュー間の埋め込みベクトルに対して平均二乗誤差 (MSE) を計算し、主損失関数に加える。
* **メリット**:
    * エンコーダに対し、「反転しても戦術的な意味（埋め込み）は変わらない」という強い制約を課すことができる。
    * データの水増し（Augmentation）以上の学習効果が期待でき、データ効率が大幅に向上する。

## 2. 構造的類似度指標による類似局面検索の高度化

### 【現状の課題】
TacticAIの類似CK検索では、グラフ全体を**平均プーリング**して得られた固定長ベクトル間の**コサイン類似度**を用いている。しかし、平均プーリングは個々の選手の相対的な位置関係や局所的な構造情報を消失させてしまう（「誰が誰の近くにいるか」という構造が無視される）という欠点がある。

### 【提案手法】
「プーリング＋コサイン類似度」に代わり、グラフのトポロジーや配置構造を直接評価する**「グラフマッチング的アプローチ」**を導入する。
* **手法**: 
    * **Graph Matching Networks**: ノード間の対応関係を考慮した類似度計算。
    * **Wasserstein距離 (Optimal Transport)**: 選手配置の集合を分布として捉え、ある配置から別の配置へ移行するための「輸送コスト」を類似度として定義。
* **メリット**:
    * 「全体的なシュート確率は近いが、守備の形が全く異なる」といった検索ミスマッチを防止できる。
    * コーチが重視する「ニアサイドの密度」や「特定の選手間の距離」といった構造的特徴を反映した検索が可能になる。
