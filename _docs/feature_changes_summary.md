# Receiver Training 入力特徴量の変更まとめ

`origin/dev`ブランチと比較して、receiver_trainingでの入力特徴量の変更点をまとめます。

## ノード特徴量（Node Features）

### 変更前（origin/dev）
- 基本的な特徴量のみ（次元数は可変）

### 変更後（現在）
**合計16次元**に統一

#### 追加された特徴量

| 次元 | 特徴量名 | 説明 | 正規化方法 |
|------|---------|------|-----------|
| **0-1** | x, y | 位置座標 | [0, 1]に正規化（field_length/widthで除算） |
| **2-3** | vx, vy | 速度 | **[-1, 1]に正規化**（70.0 m/sで除算）**←新規正規化追加** |
| **4** | height | 身長 | **[0, 1]に正規化**（2.0mで除算）**←新規正規化追加** |
| **5** | weight | 体重 | **[0, 1]に正規化**（100.0kgで除算）**←新規正規化追加** |
| **6** | ball_possession | ボール所有フラグ | 1.0/0.0 |
| **7-10** | **dx_to_kicker, dy_to_kicker, dist_to_kicker, angle_to_kicker** | **キッカーへの相対位置特徴** | **←新規追加**<br>- dx, dy: field_length/widthで正規化 [-1, 1]<br>- dist: フィールド対角線で正規化 [0, 1]<br>- angle: πで正規化 [-1, 1] |
| **11-14** | **dx_to_goal, dy_to_goal, dist_to_goal, angle_to_goal** | **ゴールへの相対位置特徴** | **←新規追加**<br>- dx, dy: field_length/widthで正規化 [-1, 1]<br>- dist: フィールド対角線で正規化 [0, 1]<br>- angle: πで正規化 [-1, 1] |
| **15** | team_id | チームID | 0=攻撃側、1=守備側 |

#### 削除された特徴量
- なし（すべて追加または改善）

#### 変更点の詳細

1. **正規化の改善**:
   - 速度（vx, vy）: 未正規化 → 70.0 m/sで正規化して[-1, 1]に変換
   - 身長（height）: 未正規化 → 2.0mで正規化して[0, 1]に変換
   - 体重（weight）: 未正規化 → 100.0kgで正規化して[0, 1]に変換

2. **相対特徴量の追加**:
   - **キッカーへの相対特徴（4次元）**: dx, dy, dist, angle
   - **ゴールへの相対特徴（4次元）**: dx, dy, dist, angle
   - これらの特徴量は動的に計算される（データから直接読み込むのではなく、kicker_idxとgoal positionから計算）

3. **キッカー検出の改善**:
   - 優先順位: `data["kicker_idx"]` → `ball_idx`（ボール所有者）
   - キッカーが見つからない場合は、相対特徴量はゼロで埋められる

## エッジ特徴量（Edge Features）

### 変更前（origin/dev）
**1次元のみ**
- `same_team`: 同じチームかどうか（1.0/0.0）

### 変更後（現在）
**10次元に拡張**

#### 追加された特徴量

| 次元 | 特徴量名 | 説明 | 正規化方法 |
|------|---------|------|-----------|
| **0** | dx | x方向の位置差 | field_lengthで正規化 [-1, 1] |
| **1** | dy | y方向の位置差 | field_widthで正規化 [-1, 1] |
| **2** | dist_ij | ノードiとjの距離 | フィールド対角線で正規化 [0, 1] |
| **3** | angle_ij | ノードiからjへの角度 | πで正規化 [-1, 1] |
| **4** | same_team | 同じチームかどうか | 1.0/0.0（維持） |
| **5** | **dvx** | **x方向の速度差** | **20.0 m/sで正規化** ←新規追加 |
| **6** | **dvy** | **y方向の速度差** | **20.0 m/sで正規化** ←新規追加 |
| **7** | **rel_speed** | **相対速度の大きさ** | **20.0 m/sで正規化** ←新規追加 |
| **8** | **from_kicker** | **キッカーから出るエッジかどうか** | **1.0/0.0** ←新規追加 |
| **9** | **to_kicker** | **キッカーへ向かうエッジかどうか** | **1.0/0.0** ←新規追加 |

#### 削除された特徴量
- なし（same_teamは維持され、他の特徴量が追加された）

#### 変更点の詳細

1. **位置ベースのエッジ特徴量（4次元）**:
   - dx, dy, dist_ij, angle_ij を追加
   - これらはノード間の空間的関係を表現

2. **速度ベースのエッジ特徴量（3次元）**:
   - dvx, dvy, rel_speed を追加
   - これらはノード間の動的な関係を表現

3. **キッカー関連のエッジ特徴量（2次元）**:
   - from_kicker: キッカーを起点とするエッジかどうか
   - to_kicker: キッカーを終点とするエッジかどうか
   - これらはキッカー中心のパス予測に有用

## まとめ

### ノード特徴量
- **次元数の変更**: 可変 → **16次元に固定**
- **追加**: 8次元（キッカー相対4次元 + ゴール相対4次元）
- **改善**: 3次元（速度、身長、体重の正規化改善）

### エッジ特徴量
- **次元数の変更**: 1次元 → **10次元に拡張**
- **追加**: 9次元（位置ベース4次元 + 速度ベース3次元 + キッカー関連2次元）
- **維持**: 1次元（same_team）

### 設定ファイルの変更
- `configs/receiver.yaml`: `input_dim: 16`, `edge_dim: 10` に更新
