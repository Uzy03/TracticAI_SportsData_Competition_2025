# コマンド一覧（提案手法: my_method）

提案手法（`my_method/`）で使用する主要コマンドの一覧です。  
既存ベースライン（`tacticai/`）とは **設定ディレクトリ** と **出力先** を分離しています。

---

## マルチタスク学習（Receiver + Shot） + Consistency（D2 4-view）

### 学習（ベースライン / 提案手法の切替）

```bash
# ベースライン（no_D2）
python -m my_method.train.train_multitask --config configs_my_method/multitask_receiver_shot_no_d2_baseline.yaml

# ベースライン（Consistencyなし）
python -m my_method.train.train_multitask --config configs_my_method/multitask_receiver_shot_d2_baseline.yaml

# 提案手法（Consistencyあり）
python -m my_method.train.train_multitask --config configs_my_method/multitask_receiver_shot_d2_consistency.yaml
```

### GPUの空き待ちしてから実行（tmux）

```bash
# 例: GPU0の空きVRAMが 8000MiB 以上になるまで待ってから実行
tmux new-session -d -s wait_my_method_consistency \
  "bash -lc 'scripts/wait_for_gpu.sh --gpu 0 --min-free-mib 8000 -- python -m my_method.train.train_multitask --config configs_my_method/multitask_receiver_shot_d2_consistency.yaml'"

# セッション確認/入室
tmux ls
tmux attach -t wait_my_method_consistency
```

### 過学習テスト（健全性チェック）

```bash
# 1サンプル overfit（最初の動作確認に推奨）
python -m my_method.train.train_multitask --config configs_my_method/multitask_receiver_shot_no_d2_overfit1_baseline.yaml
python -m my_method.train.train_multitask --config configs_my_method/multitask_receiver_shot_d2_overfit1_baseline.yaml
python -m my_method.train.train_multitask --config configs_my_method/multitask_receiver_shot_d2_overfit1_consistency.yaml

# 8サンプル overfit（1サンプルが通った後に推奨）
python -m my_method.train.train_multitask --config configs_my_method/multitask_receiver_shot_no_d2_overfit8_baseline.yaml
python -m my_method.train.train_multitask --config configs_my_method/multitask_receiver_shot_d2_overfit8_baseline.yaml
python -m my_method.train.train_multitask --config configs_my_method/multitask_receiver_shot_d2_overfit8_consistency.yaml
```

## 設定ファイル（提案手法）

- `configs_my_method/multitask_receiver_shot_no_d2_baseline.yaml`
- `configs_my_method/multitask_receiver_shot_d2_baseline.yaml`
- `configs_my_method/multitask_receiver_shot_d2_consistency.yaml`
- `configs_my_method/multitask_receiver_shot_no_d2_overfit1_baseline.yaml`
- `configs_my_method/multitask_receiver_shot_d2_overfit1_baseline.yaml`
- `configs_my_method/multitask_receiver_shot_d2_overfit1_consistency.yaml`
- `configs_my_method/multitask_receiver_shot_no_d2_overfit8_baseline.yaml`
- `configs_my_method/multitask_receiver_shot_d2_overfit8_baseline.yaml`
- `configs_my_method/multitask_receiver_shot_d2_overfit8_consistency.yaml`

### 主な設定項目

```yaml
# 出力を run_name ごとに分離する（例: baseline / consistency / overfit1_baseline など）
run_name: "baseline"

# 損失の重み
multitask:
  lambda_receiver: 1.0
  lambda_shot: 2.0
  lambda_consistency: 0.1   # baselineは0.0、提案手法は>0

# デバッグ overfit（train=val=test を同一サンプルにする）
debug_overfit:
  enabled: true
  num_samples: 1
  seed: 42
```

---

## 出力（保存先）

`run_name` によって **baseline / consistency / overfit** の結果が自動で分かれます。

### ログ / 学習履歴（CSV）

- `runs/my_method/receiver_shot/<run_name>/training_{timestamp}.log`
- `runs/my_method/receiver_shot/<run_name>/training_history_{timestamp}.csv`

### ベストモデル

- D2有効: `checkpoints/my_method/receiver_shot/<run_name>/best_d2.ckpt`
- D2無効: `checkpoints/my_method/receiver_shot/<run_name>/best_no_d2.ckpt`
