## マルチタスク学習（Receiver + Shot） + Consistency（D2 4-view）

### ⚠️ 重要: NaNエラー回避のため、まず過学習テストを実行

**フル学習を回す前に、必ず過学習テスト（1サンプル）を実行してNaNが出ないことを確認してください。**
- 過学習テストでNaNが出る場合、フル学習でも必ずNaNで落ちます
- 診断ログが詳細に出力されるため、原因特定が容易です
- 実行時間は約5-10分程度です

```bash
# 過学習テスト（1サンプル、Consistencyあり）
python -m my_method.train.train_multitask --config configs_my_method/multitask_receiver_shot_d2_overfit1_consistency.yaml

# 過学習テスト（1サンプル、ベースライン）
python -m my_method.train.train_multitask --config configs_my_method/multitask_receiver_shot_d2_overfit1_baseline.yaml
```

**NaNが出た場合の診断方法:**
- ログに `NaN/Inf loss detected!` と表示されます
- どのloss成分（receiver/shot/consistency）がNaNかが分かります
- 勾配ノルムが異常に大きい場合は `Large gradient norm` と表示されます
- パラメータにNaNが含まれている場合は `Parameter 'xxx' has NaN` と表示されます

**NaNが出た場合の対処法（診断ログから原因を特定）:**

1. **Consistency lossがNaN/極端に大きい場合:**
   - `lambda_consistency` を下げる（例: `0.01` → `0.001`）
   - または、`grad_clip.max_norm` を下げる（例: `0.5` → `0.1`）

2. **勾配ノルムが異常に大きい場合（`Large gradient norm` が出る）:**
   - `grad_clip.max_norm` を下げる（例: `0.5` → `0.1` または `0.05`）
   - `optimizer.lr` を下げる（例: `0.0005` → `0.0001`）

3. **Receiver/Shot lossがNaNの場合:**
   - `optimizer.lr` を下げる
   - `train.amp` を `false` にする（数値精度の問題の可能性）

4. **パラメータにNaNが含まれている場合:**
   - 上記の対策を組み合わせる
   - または、`configs_my_method/multitask_receiver_shot_d2_consistency_stable.yaml` を使用（最も安全な設定）

### フル学習（ベースライン / 提案手法の切替）

**過学習テストでNaNが出ないことを確認してから実行してください。**

```bash
# ベースライン（no_D2）
python -m my_method.train.train_multitask --config configs_my_method/multitask_receiver_shot_no_d2_baseline.yaml

# ベースライン（Consistencyなし）
python -m my_method.train.train_multitask --config configs_my_method/multitask_receiver_shot_d2_baseline.yaml

# ベースライン（Consistencyなし・安定性優先版 / consistency_stable と同条件で比較したいとき）
python -m my_method.train.train_multitask --config configs_my_method/multitask_receiver_shot_d2_baseline_stable.yaml

# ベースライン（no_D2・安定性優先版 / D2のconsistency_stable と同条件で比較したいとき）
python -m my_method.train.train_multitask --config configs_my_method/multitask_receiver_shot_no_d2_baseline_stable.yaml

# 提案手法（Consistencyあり）
python -m my_method.train.train_multitask --config configs_my_method/multitask_receiver_shot_d2_consistency.yaml

# 提案手法（Consistencyあり・安定性優先版 / 時間がないときの推奨）
python -m my_method.train.train_multitask --config configs_my_method/multitask_receiver_shot_d2_consistency_stable.yaml
```

※ 提案手法側のフル学習用configは、学習時間短縮のため **AMP有効（`train.amp: true`）**、**TF32有効（`train.tf32: true`）**、**DataLoader並列（`num_workers: 4`）** にしています。

### GPUの空き待ちしてから実行（tmux）

```bash
# 例: GPU0の空きVRAMが 8000MiB 以上になるまで待ってから実行
tmux new-session -d -s wait_my_method_consistency \
   "bash -lc 'bash scripts/wait_for_gpu.sh --gpu 0 --min-free-mib 8000 -- python -m my_method.train.train_multitask --config configs_my_method/multitask_receiver_shot_d2_consistency.yaml'"

# セッション確認/入室
tmux ls
tmux attach -t wait_my_method_consistency
```

※ `scripts/wait_for_gpu.sh: Permission denied` が出る場合は、上のように **`bash scripts/wait_for_gpu.sh ...`** として実行してください（実行ビット未付与でも動きます）。

### 主な設定項目

```yaml
# 出力を run_name ごとに分離する（例: baseline / consistency / overfit1_baseline など）
run_name: "baseline"

# 損失の重み
multitask:
  lambda_receiver: 1.0
  lambda_shot: 2.0
  lambda_consistency: 0.1   # baselineは0.0、提案手法は>0

# デバッグ overfit（train=val=test を同一サンプルにする）
debug_overfit:
  enabled: true
  num_samples: 1
  seed: 42
```

## 出力（保存先）

`run_name` によって **baseline / consistency / overfit** の結果が自動で分かれます。

### ログ / 学習履歴（CSV）

- `runs/my_method/receiver_shot/<run_name>/training_{timestamp}.log`
- `runs/my_method/receiver_shot/<run_name>/training_history_{timestamp}.csv`

### ベストモデル

- D2有効: `checkpoints/my_method/receiver_shot/<run_name>/best_d2.ckpt`
- D2無効: `checkpoints/my_method/receiver_shot/<run_name>/best_no_d2.ckpt`

## 類似CK検索（Retrieval：my_method）

### インデックス作成（consistency_stable / baseline_stable）

`--output-index` を省略すると、**`runs/my_method/<run_name>/indices/index_{d2|no_d2}.pkl`** に自動保存されます。

```bash
# my_method（D2 + Consistency, stable）
# -> runs/my_method/consistency_stable/indices/index_d2.pkl
python scripts/build_retrieval_index_my_method.py \
  --config configs_my_method/multitask_receiver_shot_d2_consistency_stable.yaml

# D2 baseline（stable）
# -> runs/my_method/baseline_stable/indices/index_d2.pkl
python scripts/build_retrieval_index_my_method.py \
  --config configs_my_method/multitask_receiver_shot_d2_baseline_stable.yaml
```
