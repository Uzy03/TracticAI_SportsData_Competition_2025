# 200エポック学習による性能限界の検証結果

## 実験日
2025年12月10日

## 実験設定

| 設定項目 | D2無効版 | D2有効版 |
|---------|----------|----------|
| **設定ファイル** | `configs/receiver_full_simplified_200epoch_no_d2.yaml` | `configs/receiver_full_simplified_200epoch_d2.yaml` |
| **エポック数** | 200 | 200 |
| **学習率 (lr)** | 0.001 | 0.0005 |
| **勾配クリッピング** | enabled=true, max_norm=1.0 | enabled=true, max_norm=0.5 |
| **D2等変性** | 無効 | 有効 |
| **備考** | 通常設定 | 安定化のため学習率・勾配クリッピングを調整 |

## 最終結果（200エポック目）

| 指標 | D2無効版 | D2有効版 | 差（D2有効 - D2無効） |
|------|----------|----------|----------------------|
| **Train Acc** | 0.6266 (62.66%) | 0.3766 (37.66%) | -0.2500 (-25.00%) |
| **Train Top-3** | 0.8671 (86.71%) | 0.6994 (69.94%) | -0.1677 (-16.77%) |
| **Test Acc** | 0.2281 (22.81%) | 0.2807 (28.07%) | **+0.0526 (+5.26%)** |
| **Test Top-3** | 0.4561 (45.61%) | 0.4912 (49.12%) | **+0.0351 (+3.51%)** |
| **Test Top-5** | 0.6667 (66.67%) | 0.6316 (63.16%) | -0.0351 (-3.51%) |
| **過学習度（Train-Test差）** | 39.85% | 9.59% | **-30.26%** |

## 主要な発見

### 1. 学習の安定性
- ✅ **両方とも200エポック完走**: モデル崩壊なし
- ✅ **D2有効版の安定化成功**: 学習率と勾配クリッピングの調整により、200エポックまで安定して学習が継続

### 2. Test性能の比較
- **Test Acc**: D2有効版が **+5.26%** 高い（28.07% vs 22.81%）
- **Test Top-3**: D2有効版が **+3.51%** 高い（49.12% vs 45.61%）
- **D2等変性が長期学習でも有効**: 200エポックの長期学習でもD2有効版の方が性能が高い

### 3. 過学習の観察
- **D2無効版**: Train-Test差が **39.85%**（過学習が大きい）
  - Train Acc: 62.66%, Test Acc: 22.81%
- **D2有効版**: Train-Test差が **9.59%**（過学習が小さい）
  - Train Acc: 37.66%, Test Acc: 28.07%
- **D2等変性が過学習を抑制**: D2有効版の方が一般化性能が高い

### 4. 性能の収束
- 両方とも最終20エポックでTest Top-3が安定
  - D2無効版: 0.4561
  - D2有効版: 0.4912
- 200エポックまで学習することで、性能の限界に到達

## 50エポック学習との比較

| 設定 | エポック数 | Test Acc | Test Top-3 | 変化（Top-3） |
|------|-----------|----------|------------|--------------|
| D2無効 | 50 | 0.2632 (26.32%) | 0.4561 (45.61%) | - |
| D2無効 | 200 | 0.2281 (22.81%) | 0.4561 (45.61%) | ±0.00% |
| D2有効 | 50 | 0.2632 (26.32%) | 0.4386 (43.86%) | - |
| D2有効 | 200 | 0.2807 (28.07%) | 0.4912 (49.12%) | **+5.26%** |

### 改善ポイント
- **D2無効版**: Test Top-3が **0.4561 → 0.4561**（変化なし）
- **D2有効版**: Test Top-3が **0.4386 → 0.4912**（**+5.26%向上**）

## 結論

1. **D2等変性の有効性が確認**: 200エポックの長期学習でもD2有効版の方がTest性能が高い
2. **過学習抑制効果**: D2有効版は過学習が少なく、一般化性能が高い
3. **学習の安定性**: 学習率と勾配クリッピングの調整により、D2有効版も200エポック完走可能
4. **性能の限界**: 200エポックまで学習することで、性能の限界に到達（Test Top-3 ≈ 49%）

## 推奨事項

### ハイパーパラメータ設定

| 設定項目 | D2有効時 | D2無効時 |
|---------|----------|----------|
| **学習率 (lr)** | 0.0005 | 0.001 |
| **勾配クリッピング (max_norm)** | 0.5 | 1.0 |
| **エポック数** | 200 | 200 |
| **推奨** | ✅ 長期学習でより高い性能と過学習抑制 | 短期学習でも可 |

### 推奨事項まとめ
- **D2等変性を有効にする**: 長期学習でより高い性能と過学習抑制が期待できる
- **エポック数**: 200エポックまで学習することで、性能の限界に到達可能
