# ポスター用：提案手法の変更点まとめ（TacticAIとの差分）

本資料は、コンペ発表（ポスター）向けに **TacticAIベース**からの主要な変更点を「短く・貼れる形」でまとめたもの。

---

## 変更点①：マルチタスク学習の損失（Receiver + Shot + Consistency）

### TacticAI（ベースライン）の考え方

- CK局面をグラフとしてエンコード（GNN）
- 受け手予測（ノード分類）と、シュート予測（グラフ分類）を扱う
- D2対称性（左右・上下反転）は、**4ビューを平均**して不変表現を得る（ただし、各ビューが“本当に同じ表現”になる保証は弱い）

### 提案手法（my_method）の変更点

#### (A) マルチタスク損失の統合

受け手予測とシュート予測を同時学習し、検索に使う埋め込みの汎化を促す。

\[
\mathcal{L}_{total}
= \lambda_{rec}\,\mathcal{L}_{rec}
 \lambda_{shot}\,\mathcal{L}_{shot}
 \lambda_{cons}\,\mathcal{L}_{cons}
\]

- **\(\mathcal{L}_{rec}\)**: 受け手予測（候補集合上のCE）
  - 実装上は `cand_mask`（候補選手）でロジットを絞り、候補空間でCross-Entropy
  - 目的：候補外ノイズを減らし「受け手選択」に集中
- **\(\mathcal{L}_{shot}\)**: シュート予測（BCE）
  - ノードごとのshot logitを計算→平均してグラフlogitへ
- **\(\mathcal{L}_{cons}\)**: D2の4ビュー間一貫性（後述）

#### (B) D2ビュー間の一貫性正則化（Consistency Loss）

TacticAIは4ビュー平均で不変化するが、**ビュー間で内部表現が揃う保証が弱い**。  
そこで、4ビューのノード埋め込み \(H^{(i)}\) に対して一貫性を強制：

\[
\mathcal{L}_{cons}
 = \frac{1}{|\mathcal{P}|}\sum_{(i,j)\in \mathcal{P}} \mathrm{MSE}\big(H^{(i)}, H^{(j)}\big)
\]

- \(\mathcal{P}\): 4ビューの組合せ（全ペア）
- 目的：反転しても戦術的意味（埋め込み）が変わらない、という制約を強める → データ効率/汎化を改善

#### 設定（config）

- `multitask.lambda_receiver`, `multitask.lambda_shot`, `multitask.lambda_consistency`
- 例：`configs_my_method/multitask_receiver_shot_d2_consistency_stable.yaml`

## 変更点②：類似CK戦術検索アルゴリズム（cos類似度の改良）

### TacticAI（ベースライン）

- グラフ埋め込み：ノード埋め込みを **平均プーリング**して1本のベクトルへ
- 類似度：埋め込み間の **コサイン類似度**
- 攻撃/守備を分離した埋め込みで比較（既存手法）

課題：CK位置（4象限）の絶対座標に引っ張られやすく、**同じ戦術でも角の位置が違うと類似度が低くなりやすい**。

### 提案手法（my_method）の変更点

#### 4象限（CK位置）の角反転正規化

キッカー（ball/kicker proxy）の象限に応じてノード特徴を反転し、4つのCK位置を同一視して位置依存を緩和。

- キッカーの位置（x, y）に応じて、特徴を反転：
  - x < 0 の場合：x座標を反転
  - y < 0 の場合：y座標を反転
- これにより、すべてのCKを「同一の基準角」に正規化してから埋め込みを生成
- 結果：**同じ戦術でも角の位置が違っても類似度が高くなる**

> 注意：cos検索は事前計算indexを使うため、変更後は **index再構築が必須**。

## 定性的結果（ポスター用の主張例）

- **cos類似度（ベースライン）**は上位が同じCK位置に偏りやすい
- **提案手法（角位置正規化）**により、4つのCK位置を同一視して位置依存を緩和
