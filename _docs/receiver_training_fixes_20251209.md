# Receiver予測モデルの修正と性能評価

**日付**: 2025-12-09  
**目的**: D2等変性有効時のモデル崩壊修正、候補マスキングバグ修正、D2有効/無効の性能比較

## 概要

今回の作業では、以下の2つの主要な問題を修正し、D2等変性有効/無効での性能比較を行いました：

1. **D2有効時のモデル崩壊問題の修正**（勾配クリッピングの有効化）
2. **候補マスキングとID変換のバグ修正**（`cand_counts`の累積問題）

## 1. D2有効時のモデル崩壊問題の修正

### 問題の背景

D2等変性を有効化（`d2.enabled: true`）して学習を実行した際、エポック30以降で以下の問題が発生していました：

- 異常に大きい負のロジット値（例: `-15979`）
- ノード埋め込みの分散がほぼゼロ（`H_all_std=0.000123`）
- 学習の停止・性能の急激な悪化

詳細は `_docs/d2_equivariance_fix_20251208.md` を参照。

### 修正内容

**勾配クリッピングの有効化**

`configs/receiver_full_simplified.yaml` を修正：

```yaml
train:
  grad_clip:
    enabled: true  # false から変更
    max_norm: 1.0  # 勾配の最大ノルムを1.0にクリッピング
```

**効果:**
- D2有効時もエポック30以降で安定して学習が継続
- モデル崩壊が完全に解消
- 50エポック完走を確認

## 2. 候補マスキングとID変換のバグ修正

### 問題の発見

学習中に以下のエラーが発生：

```
[TRAIN-ASSERT-FAIL] Training loss calculation: target_idx=10 must be in [0, 10), logits_shape=torch.Size([1, 12])
```

### 原因の特定

**`cand_counts`の累積問題:**

- `cand_counts`がバッチ間で累積されていた
- `graph_outputs`と`cand_counts`の長さが不一致になる可能性
- 異なるバッチのデータが混在する可能性

### 修正内容

**`tacticai/train/train_receiver.py`の修正:**

1. **`cand_counts`のスコープ修正**
   - `cand_counts`をバッチごとに初期化（`batch_cand_counts`として新規作成）
   - 各バッチで正しい`Ncand`を使用

2. **データ整合性チェックの追加**
   - `target_global`が`cand_mask`に含まれることを確認
   - `cand_target_idx`が有効範囲内（`[0, Ncand)`）であることを確認
   - `logits_b`のサイズが`Ncand`と一致することを確認

3. **検証コードの強化**
   - `train_epoch`と`validate_epoch`の両方に同様のチェックを追加
   - デバッグログの追加（`outputs.numel()`, `batch_size`, `cm.size(0)`など）

### 修正後の効果

- エラーなく50エポック完走
- データ整合性が保証される
- 損失計算が正確に実行される

## 3. D2有効 vs D2無効の性能比較

### 実験設定

- **エポック数**: 50
- **設定ファイル**: `configs/receiver_full_simplified.yaml`
- **勾配クリッピング**: 両方とも有効（`max_norm=1.0`）
- **データ**: `data/processed_ck/receiver_*`

#### 学習プロセス

| **最終損失 (Epoch 50)** | 1.9734 | 1.9737 | -0.0003 |
| **損失改善幅** | 0.2957 | 0.3372 | -0.0415 |
| **初期精度 (Epoch 1)** | 0.1962 | 0.1709 | +0.0253 |
| **最終精度 (Epoch 50)** | 0.3101 | 0.2785 | **+0.0316 (+11.36%)** |
| **精度改善幅** | 0.1139 | 0.1076 | +0.0063 |

#### テスト結果

| 指標 | D2有効 | D2無効 | 差分 |
|------|--------|--------|------|
| **Test Loss** | 2.0665 | 2.1046 | **-0.0381 (-1.81%)** |
| **Test Accuracy** | 0.2632 | 0.2632 | 0.0000 (0.00%) |

#### 安定性（エポック41-50）

| 指標 | D2有効 | D2無効 |
|------|--------|--------|
| **損失の標準偏差** | 0.0265 | 0.0184 |

| **精度の範囲** | [0.2753, 0.3101] | [0.2500, 0.3196] |

### 観察結果

1. **学習精度**: D2有効の方が**+11.36%高い**（0.3101 vs 0.2785）
   - D2等変性により学習データの特徴をより効果的に学習

2. **テスト精度**: 両方とも同じ（0.2632）
   - D2等変性の汎化への直接的な効果は限定的

3. **テスト損失**: D2有効の方が**-1.81%低い**（2.0665 vs 2.1046）
   - 過学習の兆候は低い
   - 学習が良好に進行している

4. **Top-3精度**: D2無効の方が少し高い（0.4561 vs 0.4386）
   - 統計的に有意差があるかは要検証
   - 差異は小さく（-3.85%）、実用上の影響は限定的

5. **安定性**: 両方とも正常範囲内で安定
   - モデル崩壊なし
   - 後半エポックでも安定した学習を確認
