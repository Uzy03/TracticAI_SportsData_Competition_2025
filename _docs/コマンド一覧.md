# コマンド一覧

TacticAIプロジェクトで使用する主要なコマンドの一覧です。

## 受け手予測（Receiver Prediction）

### 学習

```bash
# 基本コマンド（D2等変性無効）
python tacticai/train/train_receiver.py --config configs/receiver_full_simplified.yaml

# D2等変性有効版（設定ファイルで d2.enabled: true に設定）
python tacticai/train/train_receiver.py --config configs/receiver_full_simplified.yaml

# デバッグ用（過学習確認）
python tacticai/train/train_receiver.py --config configs/receiver_full_simplified.yaml --debug-overfit
```

### 設定ファイル

- `configs/receiver_full_simplified.yaml`: メイン設定ファイル
- `configs/receiver_full_simplified_200epoch_d2.yaml`: 200エポック学習用（D2有効）

### 出力

- ログファイル: `runs/training_{timestamp}.log`
- 学習履歴: `runs/training_history_{timestamp}.csv`
- ベストモデル: `checkpoints/receiver/best.ckpt`
- バックボーン: `checkpoints/receiver/backbone_d2.ckpt` または `backbone_no_d2.ckpt`

---

## シュート予測（Shot Prediction）

### データ生成

受け手予測のデータからシュート予測用のデータを生成：

```bash
python scripts/generate_shot_data_from_receiver.py
```

出力先: `data/processed_ck/shot_train/`, `data/processed_ck/shot_val/`, `data/processed_ck/shot_test/`

### 学習

```bash
# 基本コマンド（Pretrained backbone使用）
python tacticai/train/train_shot.py --config configs/shot_pretrained_backbone.yaml

# デバッグ用（過学習確認）
python tacticai/train/train_shot.py --config configs/shot_pretrained_backbone.yaml --debug-overfit
```

### 設定ファイル

- `configs/shot_pretrained_backbone.yaml`: メイン設定ファイル（Pretrained receiver backbone使用）

### 出力

- ログファイル: `runs/shot/training_{timestamp}.log`
- 学習履歴: `runs/shot/training_history_{timestamp}.csv`
- ベストモデル: `checkpoints/shot/best.ckpt`

## 類似CK検索システム（Similar CK Retrieval）

### インデックス構築

全データ（train + val + test）を使用してインデックスを構築します。

#### D2有効版の場合

```bash
python scripts/build_retrieval_index.py \
  --config configs/receiver_full_simplified_200epoch_d2.yaml \
  --output-index indices/receiver_index_d2.pkl
```

#### D2無効版の場合

```bash
python scripts/build_retrieval_index.py \
  --config configs/receiver_full_simplified_200epoch_no_d2.yaml \
  --output-index indices/receiver_index_no_d2.pkl
```

#### 特定のphaseのみをインデックス化する場合（オプション）

```bash
# Trainデータのみ
python scripts/build_retrieval_index.py \
  --config configs/receiver_full_simplified_200epoch_d2.yaml \
  --output-index indices/receiver_train_index_d2.pkl \
  --phase train

# Valデータのみ
python scripts/build_retrieval_index.py \
  --config configs/receiver_full_simplified_200epoch_d2.yaml \
  --output-index indices/receiver_val_index_d2.pkl \
  --phase val

# Testデータのみ
python scripts/build_retrieval_index.py \
  --config configs/receiver_full_simplified_200epoch_d2.yaml \
  --output-index indices/receiver_test_index_d2.pkl \
  --phase test
```

#### カスタムバックボーンチェックポイントを指定する場合

```bash
python scripts/build_retrieval_index.py \
  --config configs/receiver_full_simplified_200epoch_d2.yaml \
  --backbone-checkpoint checkpoints/receiver/custom_backbone.ckpt \
  --output-index indices/receiver_index_custom.pkl
```

### パラメータ説明

- `--config`: Receiver予測のconfigファイルを指定（D2有無は使用するバックボーンと一致させる必要がある）
- `--output-index`: 構築したインデックスの保存先パス
- `--phase`: （オプション）インデックス化するデータ分割（`train` / `val` / `test`）。指定しない場合は全データ（train+val+test）を使用
- `--backbone-checkpoint`: （オプション）バックボーンチェックポイントのパス。指定しない場合、configのD2設定に応じて自動選択される（`backbone_d2.ckpt`または`backbone_no_d2.ckpt`）
- `--use-faiss`: （オプション）Faissを使用した高速検索を有効化

**注意事項：**
- バッチサイズ、num_workersなどはconfigファイルから自動的に読み込まれます
- `--phase`を指定しない場合、train/val/testの全データを使用してインデックスを構築します
- インデックス構築には時間がかかる場合があります（データセットサイズに依存）

## 設定ファイルの主なオプション

### データ統合

```yaml
data:
  merge_val_to_train: true  # ValidationをTrainに統合（小データセット用）
```

### D2等変性

```yaml
d2:
  enabled: true  # D2等変性を有効化
```

### 学習設定

```yaml
train:
  batch_size: 32
  epochs: 50
  grad_clip:
    enabled: true
    max_norm: 1.0  # D2有効時は0.5を推奨
```

---

## 注意事項

1. **受け手予測の学習を先に実行**: シュート予測はpretrained receiver backboneが必要です
2. **D2設定の一致**: 受け手予測とシュート予測で`d2.enabled`を同じに設定してください
3. **データパス**: デフォルトでは`data/processed_ck/`を使用します
4. **GPUメモリ**: バッチサイズはGPUメモリに応じて調整してください

## トラブルシューティング

### メモリ不足エラー

```bash
# batch_sizeを減らす（configs/*.yamlで編集）
train:
  batch_size: 16  # 32から減らす
```

### データが見つからない

```bash
# データ生成スクリプトを実行
python scripts/generate_shot_data_from_receiver.py
```

### バックボーンが見つからない

受け手予測の学習が完了しているか確認：
```bash
ls checkpoints/receiver/backbone*.ckpt
```
